# Suporte / Support

## Como Obter Ajuda / How to Get Help

Precisando de ajuda com o Gerenciador de Funcionários? Você está no lugar certo!

Need help with the Employee Manager? You're in the right place!

### Recursos de Documentação / Documentation Resources

1. **README.md**: Informações básicas sobre configuração e uso / Basic setup and usage information
2. **docs/architecture.md**: Arquitetura detalhada do sistema / Detailed system architecture  
3. **CONTRIBUTING.md**: Guia para contribuidores / Contributors guide
4. **Wiki** (quando disponível): Tutoriais e exemplos avançados / Tutorials and advanced examples

### Opções de Suporte / Support Options

#### 🐛 Bugs e Problemas / Bugs and Issues

Se você encontrou um bug ou problema:

If you found a bug or issue:

1. **Verifique as issues existentes**: Primeiro, verifique se o problema já foi reportado
   **Check existing issues**: First, check if the issue has already been reported
2. **Crie uma nova issue**: Use nosso [template de bug report](.github/ISSUE_TEMPLATE/bug_report.md)
   **Create a new issue**: Use our [bug report template](.github/ISSUE_TEMPLATE/bug_report.md)
3. **Forneça detalhes**: Inclua passos para reproduzir, ambiente, screenshots
   **Provide details**: Include reproduction steps, environment, screenshots

#### ❓ Perguntas / Questions

Para perguntas sobre como usar o projeto:

For questions about how to use the project:

1. **Crie uma issue**: Use nosso [template de pergunta](.github/ISSUE_TEMPLATE/question.md)
   **Create an issue**: Use our [question template](.github/ISSUE_TEMPLATE/question.md)
2. **Verifique as discussões**: Consulte as discussões existentes no GitHub
   **Check discussions**: Review existing discussions on GitHub
3. **Wiki**: Consulte nossa wiki para perguntas frequentes
   **Wiki**: Check our wiki for frequently asked questions

#### 💡 Sugestões de Funcionalidades / Feature Suggestions

Tem uma ideia para melhorar o projeto?

Have an idea to improve the project?

1. **Use o template**: [Feature request template](.github/ISSUE_TEMPLATE/feature_request.md)
2. **Seja específico**: Descreva a funcionalidade e seus benefícios
   **Be specific**: Describe the feature and its benefits
3. **Considere contribuir**: Você pode implementar a funcionalidade você mesmo!
   **Consider contributing**: You can implement the feature yourself!

### Resposta Esperada / Expected Response Time

| Tipo / Type | Tempo de Resposta / Response Time |
|-------------|-----------------------------------|
| Bugs críticos / Critical bugs | 24-48 horas / hours |
| Bugs gerais / General bugs | 3-7 dias / days |
| Perguntas / Questions | 2-5 dias / days |
| Funcionalidades / Features | 1-2 semanas / weeks |

### Etiquetas de Issues / Issue Labels

Para ajudar na organização, usamos as seguintes etiquetas:

To help with organization, we use the following labels:

- 🐛 `bug`: Problemas e erros / Problems and errors
- ✨ `enhancement`: Novas funcionalidades / New features
- ❓ `question`: Perguntas e esclarecimentos / Questions and clarifications
- 📚 `documentation`: Melhorias na documentação / Documentation improvements
- 🔒 `security`: Questões de segurança / Security issues
- 🆘 `help wanted`: Contribuições bem-vindas / Contributions welcome
- 🚀 `priority-high`: Alta prioridade / High priority
- 🐌 `priority-low`: Baixa prioridade / Low priority

### Não é um Bug? / Not a Bug?

Se sua issue não é exatamente um bug, aqui estão outras opções:

If your issue isn't exactly a bug, here are other options:

#### Problemas de Configuração / Configuration Issues
- Verifique a documentação de configuração
- Check the configuration documentation
- Compare com os exemplos fornecidos
- Compare with provided examples

#### Perguntas sobre Java/Spring Boot / Java/Spring Boot Questions
- Consulte a documentação oficial do Spring Boot
- Check the official Spring Boot documentation
- Visite Stack Overflow para perguntas gerais
- Visit Stack Overflow for general questions

#### Problemas de Ambiente / Environment Issues
- Verifique se você tem a versão correta do Java (11+)
- Check if you have the correct Java version (11+)
- Verifique se o Maven está configurado corretamente
- Check if Maven is configured correctly

### Contribuindo para o Suporte / Contributing to Support

Você pode ajudar outros usuários:

You can help other users:

- **Respondendo perguntas**: Ajude nas issues marcadas como `question`
  **Answering questions**: Help with issues marked as `question`
- **Melhorando a documentação**: Corrija ou adicione informações úteis
  **Improving documentation**: Fix or add useful information
- **Reproduzindo bugs**: Confirme bugs reportados por outros
  **Reproducing bugs**: Confirm bugs reported by others
- **Testando correções**: Teste pull requests abertos
  **Testing fixes**: Test open pull requests
